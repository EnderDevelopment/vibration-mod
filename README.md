# Vibration Mod

Adds haptic feedback for block interactions in Minecraft Fabric.

## Features

- Vibration feedback when breaking blocks
- Vibration feedback when placing blocks
- Configurable vibration durations

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the latest version of the mod from the [releases page](https://github.com/EnderDevelopment/vibration-mod/releases).
2. Place the downloaded JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

The mod will automatically provide vibration feedback when you break or place blocks. You can configure the vibration durations in the configuration file.

## Configuration

The mod includes a configuration file where you can adjust the vibration durations for breaking and placing blocks. The configuration file is located in the `config` folder of your Minecraft instance.

```json
{
  "break_vibration_duration": 100,
  "place_vibration_duration": 100
}
```
